# PersonalPortfolioProject
## What is this?
PersonalPortfolioProject is a responsive multipage portfolio that represents my background, technical skills, completed coursework for Texas Tech, and planned cybersecurity and intelligence analysis projects. A visitor can nagivate between Home, Projects, About, and Resume pages, switch the color theme, and filter the project library by Security Operations, Intelligence, or Coursework.

## Why does it exist?
I built this portfolio to create a professional online record of my growth in information technology, cybersecurity, and intelligence analysis. It is intended for instructors, classmates, future potential employers, and professional contacts who want to understand my experience and review the work I have completed. Planned projects are clearly marked as Coming Soon until their case studies are finished and published.

## What tools did I use?
- **Visual Studio Code** — I used VS Code to organize and edit the project files in one development environment.
- **HTML** — I chose HTML to give each page a clear, accessible structure without relying on a framework.
- **CSS** — I used custom CSS for the layout and navigation.
- **JavaScript** — I used vanilla JavaScript for the project category filter, saved theme preference, active navigation state, and subtle reveal effects.
- **Git and GitHub** — I used version control to document changes and keep the project source organized.
- **GitHub Pages** — I chose GitHub Pages because it deploys this static project directly from the repository.
- **ChatGPT/Codex** — I used AI assistance for code suggestions, debugging, and review, then customized and tested the result myself.
